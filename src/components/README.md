# Components Directory

## Structure

### `/common`
Reusable UI components used throughout the site:
- Button
- Card
- Input
- Badge/Pill
- Modal
- Loading spinner
- Icon components
- Typography components

### `/sections`
Major page sections that combine multiple components:
- Hero (homepage hero with CTA)
- PrioritiesGrid (5 main issues)
- VideoGrid (John on the Issues)
- NewsSection (On the Record)
- EndorsementsGrid
- AboutBio
- DistrictMap
- CallToAction sections

### `/forms`
Form components and validators:
- VolunteerForm
- ContactForm
- NewsletterSignup
- FormField wrapper
- Form validation

### `/layout`
Structural layout components:
- Header/Navigation
- Footer
- PageWrapper
- Container/Grid system
- SEO/Meta tags component

## Component Guidelines

1. **Props**: Use TypeScript interfaces for prop definitions
2. **Styling**: Use consistent design system colors and spacing
3. **Accessibility**: Include ARIA labels and semantic HTML
4. **Responsive**: Mobile-first approach
5. **Performance**: Lazy load images, optimize assets
